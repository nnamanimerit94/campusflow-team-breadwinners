**# CampusFlow**

**## Project Description**

campusflow is basically a command-line helpdesk management system that recieves suppport tickets from users and helps assigns these tickets based on their priority which is calculated internally using urgency and affected_users input entered by the user when creating tickets.

**## Technology**

- Python 3
- Python Standard Library
- Git and GitHub

**## Project Features**

The project offers the following features:

- CREATE ticket
- LIST/VIEW tickets
- WORKFLOW- Support open → in_progress → resolved status of the created tickets
- ASSIGN ticket
- WORK QUEUE: Show open, unresolved tickets in critical → high → medium → low order
- REPORTS: Show total tickets and breakdowns by status and priority; handle zero tickets correctly.
- PERSISTENCE: Save to JSON and reload on startup. Missing file should allow a fresh start
